## 逐页内容

### 1) 封面
- 题目：基于 Gin 与 Nuxt.js 的跨境电商独立站的设计与实现
- 院系/专业/姓名/指导教师/答辩日期
- 讲解要点：一句话说明“做了什么系统、解决什么问题”

### 2) 研究背景与意义
- 第三方平台存在流量成本高、数据归属弱、品牌自主性不足
- 跨境场景下，独立站可直接面向海外用户并形成数据闭环
- 课题价值：完整走通“需求-设计-实现-测试”的工程实践

### 3) 研究目标与论文贡献
- 目标：构建可部署、可演示、可扩展的跨境独立站
- 三子系统：`server`、`shop_admin`、`zhuyi-store`
- 贡献：前后端分离 + 分层架构 + 多端认证 + PayPal 支付集成

### 4) 技术选型与可行性
- 后端：Go + Gin + GORM + MySQL + Redis
- 管理端：Vue3 + Vite + Ant Design Vue
- 前台：Nuxt4 + Nuxt UI + Tailwind CSS
- 可行性：技术成熟、开源成本低、部署门槛可控

### 5) 系统总体架构
- 前后端分离，RESTful API 通信
- API 分组：`/api/manage`、`/api/client`
- 认证策略：管理员 Session（Redis）、前台用户 JWT、游客设备指纹
- 外部依赖：PayPal、OSS

### 6) 核心业务流程（用户侧）
- 浏览商品 -> 商品详情 -> 选择 SKU 加购
- 购物车调整 -> 结算填写地址 -> 创建订单
- 跳转 PayPal 支付 -> 返回订单详情查询
- 游客也可通过设备指纹 + 查询码完成查单

### 7) 数据库与关键数据模型
- 商品域：分类、商品、SKU、属性、标签
- 交易域：订单、订单项、收货地址、退款
- 内容域：文档、推荐位、推荐项
- 设计原则：核心表主外键清晰、状态字段驱动流程

### 8) 后端关键设计
- 分层：Handler -> Service -> Repository -> MySQL/Redis
- Factory 统一管理依赖，降低耦合
- 中间件：CORS、管理员认证、JWT、设备指纹
- 统一响应码与错误处理，便于前端联调

### 9) 前后端关键实现
- 管理端：商品/分类/订单/CMS/系统管理模块
- 前台：首页、分类、详情、购物车、结算、订单、账户中心
- API 封装与状态管理：提升可维护性与迭代效率

### 10) 测试方案与结果
- 测试环境：Go + MySQL + Redis + Node + PayPal Sandbox
- 覆盖：管理端、客户端、接口认证、核心业务流程
- 结果：主要功能与链路全部走通，系统可部署可演示
- 未覆盖：大规模压测与安全渗透

### 11) 项目亮点与创新点
- 管理端与客户端双端协同，业务闭环完整
- 多端认证策略分层明确（Session/JWT/设备指纹）
- PayPal 沙箱支付与退款流程打通

### 12) 不足与改进方向
- 性能：缺少系统化压测与高并发优化验证
- 安全：缺少渗透测试、审计与更完整风控
- 工程质量：自动化测试覆盖不足
- 后续：补齐 CI/CD、缓存策略、索引与读写优化

### 13) 总结与致谢
- 完成了独立站从需求到测试的全流程落地
- 提升了对前后端分离与工程化开发的理解
- 致谢老师与评审，欢迎提问
