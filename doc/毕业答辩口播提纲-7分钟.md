# 毕业答辩口播提纲（7分钟版）

## 逐页讲解（对应 13 页）

1. 封面（20秒）  
“各位老师好，我的课题是《基于 Gin 与 Nuxt.js 的跨境电商独立站的设计与实现》。本课题目标是实现一套可部署、可演示、可扩展的跨境独立站系统。”

2. 研究背景与意义（30秒）  
“第三方平台在流量成本、数据归属和品牌自主性上有局限。跨境场景下，独立站能形成自有域名和数据闭环，因此我选择该方向并完成工程化落地。”

3. 研究目标与贡献（30秒）  
“我构建了三个子系统：后端 server、管理后台 shop_admin、前台商城 zhuyi-store。核心贡献是分层架构、多端认证策略和 PayPal 支付集成。”

4. 技术选型与可行性（35秒）  
“后端采用 Go+Gin+MySQL+Redis，管理端采用 Vue3+Vite+Ant Design Vue，前台采用 Nuxt4+Nuxt UI。整体技术成熟、开源成本低、可维护性较好。”

5. 系统总体架构（40秒）  
“系统为前后端分离，通过 RESTful API 通信。接口分组为 /api/manage 和 /api/client。认证方面：管理员走 Redis Session，前台用户走 JWT，游客通过设备指纹关联业务。”

6. 核心业务流程（40秒）  
“用户从浏览商品到选择 SKU 加入购物车，再到结算下单并跳转 PayPal 支付，最后回到订单详情。游客也能通过设备指纹和查询码完成查单。”

7. 数据库与关键数据模型（35秒）  
“数据库按商品域、交易域、内容域设计，覆盖分类、商品、SKU、订单、退款、文档和推荐位等核心实体，支持完整业务闭环。”

8. 后端关键设计（35秒）  
“后端采用 Handler→Service→Repository 分层，Factory 做依赖管理，中间件处理认证与跨域，统一响应结构提升了联调效率和维护性。”

9. 前后端关键实现（35秒）  
“管理端实现了商品、订单、CMS、系统管理；前台实现了首页、分类、详情、购物车、结算和账户中心，形成从运营到交易的完整链路。”

10. 测试方案与结果（40秒）  
“在 Go、MySQL、Redis、Node 与 PayPal 沙箱环境下完成功能测试与流程测试。管理端、客户端、认证与支付退款流程均通过。当前不足是尚未做系统化压测与渗透测试。”

11. 项目亮点与创新点（25秒）  
“亮点在于双端协同、多端认证分层设计以及支付闭环打通，整体体现了较完整的软件工程实践能力。”

12. 不足与改进方向（25秒）  
“下一步将重点补齐性能压测、安全审计与自动化测试，并结合缓存、索引优化和 CI/CD 进一步提升工程质量。”

13. 总结与致谢（30秒）  
“本课题完成了独立站从需求到测试的全流程实现。以上是我的答辩汇报，感谢各位老师聆听，恳请批评指正。”
